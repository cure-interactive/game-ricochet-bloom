# Game Mode Illustrations

Seven original SVG scenes identify Campaign, Free Play, Endless Waves, Challenge, Reaction Puzzle, Cargo Rescue and Outbreak Containment. The geometry and compositions were authored for Ricochet Bloom; no external artwork was traced or embedded.
