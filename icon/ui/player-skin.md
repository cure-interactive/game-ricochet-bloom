# player-skin.svg

[Artwork](player-skin.svg). A bubble with an appearance sparkle. Original geometric artwork created for Ricochet Bloom by Cure Interactive. Inspired by the collection’s bold silhouettes and rounded geometry; no external source artwork copied.

Retired navigation artwork, retained for provenance. Player controls use the equipped skin material in `skin.css`; do not use this SVG or a duck glyph for player actions.
