# Skill Type Icons

Original Cure Interactive game artwork for Motion, Flow, Control, Propagation and Navigation. These 48-unit SVGs use rounded 4-unit strokes and the game’s existing pale mint ink. Type describes a skill’s behavior; rarity provides its color and prerequisite links determine its map position.

- [Motion](motion.svg): a moving body and directional chevron.
- [Flow](flow.svg): three parallel currents.
- [Control](control.svg): a contained body and braking bars.
- [Propagation](propagation.svg): one contact branching into two.
- [Navigation](navigation.svg): a compass bearing.
